# 主阅读路径与具体推导

两档均在设计主线时加载。目标是把读者原本要在脑中完成的结构识别、关系连接和阅读排序外化出来，同时让长文主线以 3—5 分钟读完。

## 一、先分主线与细节

给轻量内容草图或正式内容地图中的每个输出节点标记 `M`（主阅读路径）或 `D`（细节层）。日常档可只在内部草图中标记，完整档在内容地图中登记。

| 判断 | M：主阅读路径 | D：细节层 |
|---|---|---|
| 阅读职责 | 理解核心问题、作者结论及其成立过程不可缺少 | 支撑、说明、补充或限定某个主线节点 |
| 典型内容 | 核心主张、关键理由、必要推理、关键反方与回应、结论边界 | 完整例子、数据口径、引语、次要证据、背景、旁支、过程细节 |
| 默认呈现 | 直接可见，按编号连续阅读 | Markdown 就近置后；HTML 就近折叠或下钻 |
| 删除测试 | 删除后核心推导断裂，必须保留 | 删除后主线仍成立，但理解或核验材料减少 |

规则：

1. 核心论证不得为缩短主线而折叠或删除；细节也不得为「完整」而全部进入主线。
2. 关键反方、实施条件和结论限制若会改变结论含义，属于主线，不得当作次要细节隐藏。
3. Markdown 用「主阅读路径／按需细节」分区或同级节点的下级清单实现按需阅读；HTML 用原生展开控件，不把全部正文藏起。
4. 短文按实际所需长度输出，不为达到 3 分钟而重复或补写。

## 二、每个板块回答一个具体问题

板块标题优先写读者能理解的问题或具体职责，不只写抽象类别。

| 抽象标签 | 更具体的表达 |
|---|---|
| 痛点 | 谁在使用时遇到什么问题？ |
| 约束 | 谁担心方案带来什么代价？ |
| 判断标准 | 如何验证，以及何时退出？ |
| 机制 | 哪个环节通过什么过程改变结果？ |
| 证据 | 哪项材料支持哪一个具体判断？ |

不必把这些问句机械替换到所有文章。叙事可问「什么事件改变了后续走向」，访谈可问「谁在什么语境下持什么不同判断」。禁止为统一模板而改变原文结构。

## 三、为关键连接写具体桥接句

为主线上的每个关键连接核对下表要素；日常档可不生成正式表格，完整档在内容地图中登记：

| 起点具体内容 | 推理／条件 | 终点具体内容 | 原文依据与归属 | 为什么此刻读下一板块 |
|---|---|---|---|---|
| 上班族白天无法到馆 | 因为目标群体只有晚间可能使用 | 需要延长晚间开放时间 | 作者主张；S002—S003 | 先说明需求，再进入方案代价 |

输出的桥接句必须能让读者直接看出连接，例如：

> 上班族白天无法到馆，**所以**晚间是否可用决定了他们能否使用图书馆；**但**延长时间还会带来成本问题，下一步需要检验方案是否值得持续执行。

「支撑」「前提」「连续论证」等类型可作为小标签保留，但不得替代上句。若桥接需要原文未明说的推理，标注「推断（非原文明述）」；无法可靠连接时保留并列或原文顺序，不虚构逻辑。

### 读者补脑测试

逐个检查主线连接：

1. 只看箭头两端和桥接句，能否说出「A 的什么内容导致、支持、限制或引出 B」？
2. 能否看出为什么现在读 B，而不是稍后再读？
3. 是否还需要读者自己补充主体、条件、推理动作或结论？

任一关键连接答案为否，先重写连接，不用增加箭头、颜色或卡片掩盖。

## 四、长难句就近拆解

只有原句阻碍理解时，在主线路径附近拆成「主体｜动作／判断｜条件｜结果｜归属」等命题单元；完整原句保留在细节层。不得把全文另写一遍形成重复正文，也不得为拆句丢失限制和不确定性。

## 五、3—5 分钟主线预算

1. 优先让未参与生成的读者按正常速度实测，记录人数、起止时间和是否只读主线。
2. 无法实测时，用 `scripts/estimate_main_path.py` 做保守文本估算，并在输出或验证记录中写明「估算，非实测」。该工具只估算文字阅读时间，不能证明图示理解成本或核心论证完整。
3. Markdown 在主阅读路径首尾放置 `<!-- main-reading-path:start -->` 与 `<!-- main-reading-path:end -->`；HTML 在主线路径容器上设置 `data-main-reading-path`。
4. 长文估算超过 5 分钟时，先把完整例子、数据堆叠、次要证据与旁支移回细节层，并压缩重复表达；不得删除核心推导。低于 3 分钟时检查是否漏掉关键反方、条件或结论边界。
5. 若核心论证完整与 5 分钟上限发生冲突，不静默省略；交付当前候选并明确冲突和未达标项。

示例：

```bash
python3 scripts/estimate_main_path.py output.md --enforce
python3 scripts/estimate_main_path.py short-output.md --allow-short --enforce
python3 scripts/estimate_main_path.py output.html --enforce
```

## 六、完成前复述测试

只读主线的读者应能复述：

- 核心问题与作者结论／事件落点；
- 各板块分别回答什么；
- 关键结论经过哪些具体步骤成立；
- 主要反方、条件、例外和不确定性；
- 哪些细节可以按需展开，分别用于说明或核验什么。

不能复述时，回到主线分配或桥接句修订，不通过增加装饰图解决。
