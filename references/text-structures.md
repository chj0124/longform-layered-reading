# 文本结构：六类长文的判定信号与内容地图要点

仅在步骤 2（判断文本组织方式）加载。规则只覆盖基线与评分契约已固定的结构要求，不新增假设性禁令。

内容地图“关系”字段的取值枚举：独立支撑、必要前提、共同作用、对照、时间、部分—整体、阐释、延伸外推。判定类型后据此为顶层单元标注关系。

## 1. 论说型（观点随笔、专栏）

- **可观察信号**：第一人称主张；理由—论证结构；个人经历作论据；结尾向行业外推。
- **内容地图要点**：中心主张；每个支撑理由及其独立性（并列还是前提链）；证据与案例的归属；作者个人选择 vs 对行业/未来的判断。
- **不可省略**：各独立理由至少可回认；关键案例（谁的经历、什么数据）；结论成立条件。
- **常见误读**：把独立理由排成单线链；把"事实宣告"式预测写成事实；把个人选择普遍化成对他人的建议。

## 2. 论文 / 研究型

- **可观察信号**：明确研究问题；样本与方法；统计结果；局限；作者自设结论边界。
- **内容地图要点**：问题—方法—结果—限制四层；相关与因果的表述边界；外推边界。
- **不可省略**：方法（样本量、测量方式）；结果的方向与强度；至少两项限制的具体内容。
- **常见误读**：为压缩删光限制；把相关写成因果；以该研究为依据给出制度建议。

## 3. 行业报告

- **可观察信号**：数据与口径；发现；解释；建议；预测；涉及的利益相关者。
- **内容地图要点**：每条数据的来源与口径；发现与建议分属不同层级；预测归属主体。
- **不可省略**：数据口径；样本边界；建议是谁提出的。
- **常见误读**：把报告建议写成事实结论；丢失样本边界声明。

## 4. 访谈

- **可观察信号**：多名说话者；各自语境；共识与分歧；记者说明或结尾交代。
- **内容地图要点**：每个声音单独成单元，挂人物与语境；共识与分歧并列保留；结尾无统一结论时如实保留。
- **声音四元组（结构契约）**：每个保留的声音必须能回认为「说话者｜观察语境｜主张｜依据/引语」四元组；压缩只动措辞，不得删去使主张可回认、可解释的观察语境（位置、年限、场景、数据口径等）。交付前对照原文逐元组核验，缺一项即回到内容地图补全。
- **不可省略**：谁主张、基于什么观察（可回认）；冲突解释不被合并；未回答的部分。
- **常见误读**：合并成"有人认为"；虚构受访者和解；丢失语境导致主张无法回认。

## 5. 历史、调查与叙事

- **可观察信号**：时间线；转折点；人物自述动机；作者事后解释。
- **内容地图要点**：以时间与事件为主干，不强行提炼论点；动机与解释按来源归因（本人自述 / 作者评述）；带日期的引语记录「记录日期」与「所述事件日期」两个字段。
- **第一人称动机（结构契约）**：人物自述且承载关键动机的引语，必须保留为可回认的「说话者＋陈述时间＋原话或原意」，陈述时间随引语标注；同年发生的事件事实或后来的回忆、转述不得替代该动机引语。压缩只动措辞，不得以字数压力删除动机本身。
- **引语日期归属（结构契约）**：日志、日记、访谈、事后回忆等带日期出处的引语，不得继承相邻时间线节点或相邻事件的日期；记录日期与所述事件日期不同时，该引语单列节点，或在其引用处显式标注记录日期与出处类型。
- **不可省略**：转折点；人物自述的原意；事后解释标注为事后判断。
- **常见误读**：把时间先后写成因果（"X 杀死了 Y"式）；把作者解释写成当事人当时的认识。

## 6. 混合型

- **可观察信号**：同一文本并存调查数据、人物引语、编辑建议等多种关系。
- **内容地图要点**：允许不同部分采用不同关系与结构，不强制一张图统一全文。
- **不可省略**：任一部分不得因"结构不统一"被删改；事实、引语、建议分层归属；样本边界声明。
- **常见误读**：把引语写成调查发现；把编辑建议写成受访者诉求；把三类内容塞进同一维度的表格。
