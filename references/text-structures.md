# 文本结构识别

在步骤 3 使用。日常档把判断写进轻量内容草图，完整档映射到正式内容地图。结构标签只是索引，具体关系必须落到信息内容上。

## 1. 常见结构及阅读重点

| 结构 | 要找出 | 常见误改 |
|---|---|---|
| 时间推进 | 事件、阶段、转折 | 把先后写成因果 |
| 因果机制 | 原因、机制、结果、边界 | 跳过机制，只写「导致」 |
| 条件分支 | 条件、不同结果、共同前提 | 把有条件结论写成普遍结论 |
| 对比 | 对象、维度、同异、比较目的 | 把对比写成单纯优缺点 |
| 问题—原因—方案 | 问题定义、原因对应、方案限制 | 方案与原因错配 |
| 主张—证据 | 主张、证据、证据强度 | 把例子写成充分证明 |
| 反驳—回应 | 原主张、反例、回应、未解决处 | 只保留回应，删掉反例 |
| 多主体互动 | 各自动作、影响对象、反馈 | 合并主体或写反方向 |
| 汇聚 | 各支线、共同结果、汇聚条件 | 只写最终结论，丢掉支线 |
| 循环／反馈 | 回路方向、增强或抑制、退出条件 | 排成一次性直线流程 |

一篇文章可混合多种结构。先判断每段在整体论证中承担什么功能，再决定主线和细节。

## 2. 长难句拆解

先找主干：谁，对什么，做了什么／作出什么判断。

再拆出：

- 条件：在什么情况下。
- 限定：对哪个范围、到何种程度。
- 原因与目的：为什么、为了什么。
- 并列项：有几项，是否同一层级。
- 让步与转折：作者保留什么，又否定什么。
- 证据与归属：谁说的，依据是什么。

拆成短句后，用明确连接词恢复关系。不要把修饰语全部删掉后只留下主干。

## 3. 段落功能

给段落标注功能，有助于识别隐藏连接：

```text
提出问题／给出回答／解释概念／推进机制／提供证据／
举例／限定／让步／反驳／回应／转换话题／收束
```

如果一段同时承担多个功能，登记多个关系，不必强行只选一个。

## 4. 关系字段

轻量草图或正式内容地图中，关键关系至少可还原为：

```text
起点单元／具体内容
关系类型
推理、证据或成立条件
终点单元／具体内容
归属与不确定性
```

「A → B」只有方向，没有足够信息。必须能回答为什么能从 A 到 B。

## 5. 复杂关系的最小表达

### 条件分支

```text
共同前提
├─ 条件 1 → 结果 1
└─ 条件 2 → 结果 2
```

### 多主体互动

```text
主体 A 的具体动作 → 影响主体 B 的哪个条件
主体 B 的回应 → 反过来改变 A 的什么判断
```

### 汇聚

```text
支线 1 的具体结果 ┐
支线 2 的具体结果 ┼→ 共同结果及其条件
支线 3 的具体结果 ┘
```

### 反馈

```text
A 改变 B → B 的变化再改变 A 的哪一部分
```

写明增强还是抑制，以及原文是否给出退出条件。

## 6. 结构异常是回退信号

日常档中，如果多线、汇聚、反馈或跨段回指第一遍后仍不稳定，不要继续凭感觉排版。回退完整档，补做信息清单与关系登记。

如果结构清楚但原文缺失，则先补齐文本；完整审计不能替代原文。

## 7. 结构验收

- 每个核心判断都有来路，且来路具体。
- 每条关键证据都知道支撑哪个判断。
- 每个反例和限定都没有被主线吞掉。
- 图形、导航和正文没有三套不同关系。
- 读者能从任一跨板块箭头说出「从什么，经过什么，到什么」。
