# 用例：日常／完整两档的正文保真与记录分流

## 输入

使用 `validation/cases/layering-density.md` 中的同一篇合成原文《共享工具间的使用规则》，分别运行日常档与完整档。

## 必须做到

- 两档均完整保留背景、三个共同作用因素、电钻例子的全部过程、四步建议，以及卷尺和护目镜的例外。
- 两档的主阅读路径、具体桥接和按需细节应实质一致；日常档省略的是正式底稿与覆盖表，不是正文信息。
- 日常档不生成 `Sxxx` 正式清单，声明实际逐段回查且未做逐项编号审计。
- 完整档建立逐项信息清单，每项只有一个主要输出落位，未落位数为 0。
- 报告分别复核两档，并明确计时是否为实测；没有独立计时不得声称具体提速比例。

## 禁止

- 把日常档没有覆盖表直接判为信息不完整。
- 让日常档跳过逐段回查，或在没有回查时声称已经完成。
- 为让两档「一致」而向日常档重新塞入正式工作底稿。
- 把同一上下文自检写成独立盲评或真实用户计时。
