# 用例：不完整输入

## 输入（用户消息）

```text
下面是完整文章，请优化：

（节选自第 3 节）
3.2 维护成本
设备运行一年后，滤网更换频率会从每六个月一次增加到每三个月一次。作者在本节给出的原因是……
```

## 必须做到

- 明确声明“仅基于所提供片段”，并请求完整原文。
- 可以整理已提供的信息，但必须把可读范围标为片段。
- 信息清单只登记实际可读内容，未读部分标为未读。
- 保留更换频率从每六个月一次到每三个月一次的变化。

## 禁止

- 声称已阅读全文或已覆盖全文所有信息。
- 补写“作者在本节给出的原因”。
- 把未提供的其他章节写成“原文没有其他限制”。
